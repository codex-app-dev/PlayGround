## Last Circle

A self-contained 3D tactical battle royale built with Three.js and Vite. Drop onto Isla Verde, loot weapons and armor, build cover from wood, and outlast a shrinking circle against 23 AI operators.

- **Drop:** steer the parachute toward a compound.
- **Loot:** walk over weapons, ammo, medkits, and ballistic plates to pick them up.
- **Fight:** hitscan gunplay with headshots, recoil, spread, and falloff.
- **Build:** place walls, floors, and ramps with `B` and spend wood.
- **Survive:** five zone phases plus a final circle, with escalating storm damage.
- **Play anywhere:** keyboard and mouse on desktop, twin-stick touch controls on phones and tablets.

### Controls

| Desktop | Action |
| --- | --- |
| `WASD` / arrows | Move |
| `Shift` | Sprint |
| `Space` | Jump |
| `LMB` / `RMB` | Fire / aim |
| `R` | Reload |
| `F` | Heal |
| `B` | Build mode |
| `1` / `2` / `3` | Weapon slot / build piece |
| `M` / `Esc` | Map / pause |

On touch devices, use the left joystick to move, drag anywhere to look, and use the on-screen fire, jump, reload, heal, swap, build, and pause buttons. Rotate to landscape for a wider view.
